## New Features
- **Group Detail** — Tap on a group from the library to see nested groups and each podcast’s latest episodes.
- **Continuous Playback Source** — A Continuous Playback item now appears in both podcast and episode context menus so you can set that podcast or group as the source.
- **Bulk Archive** — Archive every episode in a podcast, only the episodes currently on screen, or everything older than a chosen episode.
- **Archive When Played** — Added a new option in podcast settings to automatically archive episodes after they’ve been played.
