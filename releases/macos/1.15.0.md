## New Features
- **Group Detail** — Click on a group in the sidebar to see nested groups and each podcast’s latest episodes.
- **Continuous Playback Source** — A Continuous Playback item now appears in both podcast and episode context menus so you can set that podcast or group as the source.
- **Archive When Played** — Added a new option in podcast settings to automatically archive episodes after they’ve been played.
- **Notification Sounds** — Silence Mimir notification sounds from Playback preferences, or from System Settings → Notifications → Mimir → Play sound for notifications.

## Bug Fixes
- Fixed switches in the podcast settings sheet appearing empty the first time the sheet opened.
