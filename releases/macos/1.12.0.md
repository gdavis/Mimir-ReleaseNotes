- **More playback speeds** — Choose from a new set of default speeds, or enter your own desired speed from 0.5x to 3.0x using 0.1 increments.

## Bug Fixes
- Fixed an issue with the audio player where some audio formats using sample rates other than 44 kHz could skip forward to the wrong position.
