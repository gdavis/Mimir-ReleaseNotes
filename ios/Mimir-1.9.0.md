# More Playback Speeds
*Release 1.9.0 – July 2026*

- Added more playback speeds. You can now choose from a new set of default speeds, or enter your own desired speed from 0.5x-3.0x using 0.1 increments. 
- Fixed an issue with the audio player where some audio formats using formats other than 44k sample rates could skip forward to the wrong position
